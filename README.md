# Store download hosting (retired)

This branch hosted direct-download URLs for the Microsoft Store EXE product ("PhoneDesk Classic", Store ID XPFD7Z5V0SHCCH), which the Store rejects since policy 10.2.9 requires signed EXE packages.
PhoneDesk is now delivered as an MSIX package through the Store product 9MVR67P7JXXX (https://apps.microsoft.com/detail/9MVR67P7JXXX); the Classic product was made unavailable on 2026-10-31 and the store/ folder was removed.
Download installers from https://github.com/realgarit/phonedesk/releases instead.
